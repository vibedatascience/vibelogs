What should a generalized Data Science Agent look like?

Authored by Rahul Chaudhary

Disclaimer: The opinions here are my own and not those of my employer.

With the advent of powerful foundation models, it was inevitable that enterprises would set up their own data agents. But since this is a new field, there isn't a lot of research or guidance out there on what makes a great DS agent or on the best way to set one up. The main goal of this post is to see what research exists and to lay out, in the author's opinion, how a great Data Science Agent should be set up.
