Reviving worldfootballR: the data sources and the update plan

worldfootballR is the package most R users reach for when they want football data. It has 75 exported functions covering FBref, Transfermarkt, and Understat, plus a companion data repository so people can load pre-collected tables without scraping anything. In September 2025 the author archived it and wrote that anyone was welcome to take it as the bones of a version 2. A year later it still gets 700 to 900 CRAN downloads a month, and the data it serves stopped on September 16, 2025.

I have been using it for a while and I have offered to take over maintenance. The continuation lives at vibedatascience/worldfootballR. It already passes R CMD check on current R with two upstream check problems fixed, and it ships a small script that calls one function per source against the live site and records what happened. This post explains what each source is, what state it is in today, and how the package will stay current from here.

What the first live run found

I ran the status script on September 8, 2026 from a cloud machine. The short version is that the Understat parsers are broken by a site change, the Transfermarkt league lookups fail because they read the frozen data repository, and the load functions work but serve year-old data. FBref returned 403, which is Sports Reference blocking datacentre IPs rather than proof that the parsers are dead; that needs a re-run from a home connection.

The sources

Three of these are what the package already covers. Four are additions chosen because their terms allow automated access without argument. Each card says what the source gives you, how far back it goes, what the site allows, and where it stands right now.

FBref

needs verification

The deepest free source of match and season statistics. Player and team tables for shooting, passing, possession, defence, and keeper stats, match reports with lineups and events, scouting reports, and advanced stats for the big five leagues and many more. Powered by Opta data through Sports Reference.

Coverage
Big five leagues with advanced stats from 2017/18, basic results for dozens of competitions going back decades.
Terms
Sports Reference publishes a bot policy with a request rate limit. The package will enforce that limit by default and users can slow it down but not remove it.
In package
24 functions, the largest source. First job is a proper live run from a residential IP to see which parsers still match the HTML.

Understat

broken, fix in progress

Expected goals. Shot-level xG for every shot in six leagues (Premier League, La Liga, Bundesliga, Serie A, Ligue 1, Russian Premier League), plus player and team season aggregates for xG, xA, npxG, xGChain, and xGBuildup.

Coverage
2014/15 to the current season, six leagues.
Terms
No published policy. The package reads JSON that the site embeds in its own pages, at a rate of one request every two seconds.
In package
11 functions. All of them currently fail with "second argument must be a list" because the site changed how it embeds the JSON. This is the first parser fix on the list.

Transfermarkt

works, lookups frozen

Market values, transfer history and fees, squads, contract details, injuries, and staff. The only free source of a consistent valuation series for every player in the world.

Coverage
Valuations back to the early 2000s, transfers much further.
Terms
Their terms prohibit automated access. The functions stay in the package and get bug fixes, but Transfermarkt is not part of any funded or scheduled data collection, and the data repository will not refresh it.
In package
20 functions. The league and team URL lookups read from the frozen data repository, so anything asking for the 2025/26 season fails today. Rebuilding those lookup tables fixes most of it.

football-data.co.uk

new

Results and bookmaker odds as plain CSV files, one per league per season. Full-time and half-time scores, shots, corners, cards, and closing odds from a dozen bookmakers. It is the dataset most betting and forecasting papers are built on.

Coverage
22 leagues, from 1993/94 to the current season, updated within a day of matches.
Terms
Free to download and use. No scraping involved; the files are published for exactly this purpose.
Plan
One function to read any league and season, one load function backed by the weekly refresh.

ClubElo

new

Elo ratings for every European club, recomputed after every match. The cleanest single number for "how good is this team right now", and the standard baseline for match forecasting.

Coverage
1946 to the current week, every club in Europe's top divisions and most second tiers.
Terms
Public API at api.clubelo.com, returns CSV, the author encourages use.
Plan
Functions for a club's rating history and for the full table on a given date.

International results

new

Every men's international match on record: date, teams, score, tournament, venue, and whether it was played at a neutral ground. Maintained as an open dataset by Mart Jürisoo and mirrored on Kaggle.

Coverage
48,000 matches from 1872 to the current month, 288 teams including historical names.
Terms
CC BY 4.0.
Plan
A single load function with the country name mapping table attached, so historical names resolve to current ones.

Reep player register

new

The missing join key. A public register of 488,000 players with their IDs on FBref, Understat, Transfermarkt, Sofascore, Opta, StatsBomb, and about 30 other providers. Without it, matching a player across two sources means fuzzy name matching and manual cleanup.

Coverage
Active and recent players across all major providers.
Terms
Public CSV on GitHub.
Plan
A join_ids() helper so a table from any source can be keyed to any other source in one call.

StatsBomb open data

later

Event-level data: every pass, shot, carry, and duel with pitch coordinates and xG, plus 360 freeze frames for some competitions. 80 competition-seasons across 24 competitions including World Cups, Euros, Champions League, and full seasons of major leagues.

Terms
Open license for non-commercial use with attribution.
Plan
StatsBombR already exists on GitHub. Loaders for worldfootballR come after the core revival, not before.

Sources that stay out

GOTCHA · FOTMOB
FotMob was removed from the package in 2024 when its terms changed to prohibit automated access. It stays out. Nothing in this continuation touches it.

The same rule applies to anything that requires another site's private API token, and to prediction markets or betting exchanges. If a source does not publish either a file, an API, or a bot policy, it does not get a scheduled job.

How the package stays current

The reason the package went stale is structural, not personal. One maintainer, one repository, and every site change landing as a bug report that only that person can fix. The fix is to make breakage visible automatically and to make most users never hit the sites at all.

  weekly GitHub Actions
  ┌──────────────────────────────────────────────────┐
  │  Monday 07:00 UTC   live_check.R                  │
  │    one call per source  →  inst/status/live_status.csv
  │                                                   │
  │  Monday 06:00 UTC   worldfootballR_data refresh   │
  │    football-data.co.uk  ─┐                        │
  │    ClubElo               ├─→  CSV + Parquet + manifest.json
  │    international results ─┤       (GitHub release assets)
  │    Understat aggregates  ─┘                        │
  └──────────────────────────────────────────────────┘
                     │
                     ▼
     load_*()  reads manifest.json, fetches latest file
     fb_*()  tm_*()  understat_*()  hit the site, rate limited
  1. A weekly live check calls one representative function per source and commits the result to the repository. When a site changes, the status file goes red within seven days instead of waiting for someone to file an issue.
  2. The data repository comes back to life on a weekly cron. Every dataset behind a load function gets rebuilt, published as CSV and Parquet with a manifest that records the timestamp, and the load functions read the manifest to find the latest file. Most users should never scrape.
  3. The package splits into one package per source (fbrefR, understatR, transfermarktR) with worldfootballR as a meta-package that re-exports everything under the current names. Existing code keeps working, and a break in one site can be fixed and released without touching the others.
  4. Rate limits become a shared helper with per-source defaults that follow each site's published policy. Users can slow requests down. They cannot switch the limit off.
  5. Every function that cannot be fixed gets a deprecation message that says why, and the last good snapshot of its data stays available through the data repository with a date stamp.

If you use the package, the most useful thing you can do is open an issue on the continuation repository for any function that fails for you, with the call and the error. The status script only covers one function per source; your failures cover the rest.
