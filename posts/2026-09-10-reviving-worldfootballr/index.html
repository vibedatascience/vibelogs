The sources

FBref

needs verification

Match and season stats. Shooting, passing, possession, defence, keepers, lineups, scouting reports. Opta data via Sports Reference.

Coverage
Big five advanced stats from 2017/18, basic results for dozens of competitions.
Terms
Published bot policy with rate limit. Enforced by default.
In package
24 functions. Needs a live run from a residential IP.

Understat

broken, fix in progress

Shot-level xG, six leagues. Player and team xG, xA, npxG, xGChain, xGBuildup.

Coverage
2014/15 to now, six leagues.
Terms
No published policy. One request per two seconds.
In package
11 functions. All fail, site changed its embedded JSON. First fix.

Transfermarkt

works, lookups frozen

Market values, transfers and fees, squads, contracts, injuries.

Coverage
Valuations from early 2000s, transfers further.
Terms
Terms prohibit automated access. Bug fixes only, no scheduled collection.
In package
20 functions. Lookups read the frozen data repo, 2025/26 fails. Rebuild lookups.

football-data.co.uk

new

Results and bookmaker odds as CSV, one file per league per season.

Coverage
22 leagues, 1993/94 to now, updated daily.
Terms
Free files, no scraping.
Plan
One read function, one load function on the weekly refresh.

ClubElo

new

Club Elo ratings, recomputed after every match.

Coverage
1946 to now, European top divisions and most second tiers.
Terms
Public CSV API at api.clubelo.com.
Plan
Club history and full table by date.

International results

new

Every men's international match: date, teams, score, tournament, venue, neutral flag. Maintained by Mart Jürisoo.

Coverage
48,000 matches, 1872 to now, 288 teams.
Terms
CC BY 4.0.
Plan
One load function with the country name mapping.

Reep player register

new

488,000 players with IDs across FBref, Understat, Transfermarkt, Sofascore, Opta, StatsBomb, and 30 more providers.

Coverage
Active and recent players.
Terms
Public CSV on GitHub.
Plan
join_ids() helper.

StatsBomb open data

later

Event data with coordinates and xG. 80 competition-seasons, 24 competitions.

Terms
Open license, non-commercial, attribution.
Plan
After the core revival. StatsBombR exists on GitHub.

Sources that stay out

GOTCHA · FOTMOB
Removed in 2024 when terms changed. Stays out. Same rule for anything needing a private token, and for betting markets.

Update plan

  weekly GitHub Actions
  ┌──────────────────────────────────────────────────┐
  │  Monday 07:00 UTC   live_check.R                  │
  │    one call per source  →  inst/status/live_status.csv
  │                                                   │
  │  Monday 06:00 UTC   worldfootballR_data refresh   │
  │    football-data.co.uk  ─┐                        │
  │    ClubElo               ├─→  CSV + Parquet + manifest.json
  │    international results ─┤       (GitHub release assets)
  │    Understat aggregates  ─┘                        │
  └──────────────────────────────────────────────────┘
                     │
                     ▼
     load_*()  reads manifest.json, fetches latest file
     fb_*()  tm_*()  understat_*()  hit the site, rate limited
  1. Weekly live check, one function per source, result committed. Site changes show up within seven days.
  2. Weekly data refresh. CSV and Parquet with a manifest. load_*() reads the manifest. Most users never scrape.
  3. One package per source (fbrefR, understatR, transfermarktR). worldfootballR re-exports under current names. Existing code keeps working.
  4. Shared rate limiter, per-source defaults from each site's policy. Users can slow it, not remove it.
  5. Unfixable functions get a deprecation message and a dated last snapshot in the data repo.
