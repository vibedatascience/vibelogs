Lecture 1: Introduction to neural networks and deep learning

VideoSlidesLengthColab
YouTubeOCW56 minnone, this one is all concepts

The problem

  • AI was founded at the 1956 Dartmouth workshop. Minsky, McCarthy, and Shannon were all MIT.
  • The decades since have produced a sequence of breakthroughs, each one an answer to the previous approach's failure:
traditional AI interview experts, hand-write if-then rules │ fails: Polanyi's paradox, no generalization ▼ machine learning learn input→output mapping from examples │ fails on unstructured data (images, text, audio) ▼ deep learning learns the representation itself, automatically │ ▼ generative AI deep learning that produces unstructured output
  • Traditional AI: ask human experts how they do the task, write if-then rules, program the rules. Fails twice. Polanyi's paradox: we know more than we can tell. And hand-written rules cannot cover situations nobody anticipated.
  • Machine learning: give the computer input-output examples and learn the mapping statistically. Huge impact (credit scoring, loan granting, disease prediction, demand forecasting), but only where the input is structured.
  • Structured data: data you can numericalize into a spreadsheet.
  • The raw form of unstructured data has no intrinsic meaning. An image is three tables of 0-255 numbers for red, green, and blue light. A 251 in the blue table says nothing about what the object is.
  • The workaround was to manually build a representation first (feature extraction). Massive human effort, and this human bottleneck sharply limited the reach of ML.

The idea

  • Deep learning extracts representations automatically from raw unstructured data, then feeds them to what is basically linear or logistic regression at the end.
  • This demolishes the human bottleneck.
  • The breakthrough came from three forces: new algorithmic ideas, unprecedented data from the digitization of everything, and GPU compute, applied to an old ML idea, neural networks.
  • Immediate application: every sensor in the world can be given the ability to detect, recognize, and classify what it is sensing.

What is a neural network?

  • Start at the beginning: recall logistic regression. Inputs [x1, x2, ..., xk] go in, a probability comes out.
  • Worked example: predict who gets called for a job interview from GPA and experience. Fitting the model gives intercept 0.4 and coefficients 0.2 (GPA) and 0.5 (experience).
  • The formula can be rewritten as a network of mathematical operations: input data flowing through two functions that have been connected. First a linear sum, then the sigmoid. Data flows left to right.

P(interview) = σ(0.4 + 0.2·GPA + 0.5·exp) = 1 1 + e−(0.4 + 0.2·GPA + 0.5·exp)

GPA ────0.2───┐ ├──▶ (+) ──▶ σ ──▶ P(interview) exp ────0.5───┘ ▲ │ 0.4 (bias)
  • Terminology swap: coefficients are weights, the intercept is a bias.
KEY IDEA · WHY THE NETWORK LENS
The moment you write the model as a network, you realize you can do lots of things in the middle. You do not have to go from input straight to output. The middle is where the automatic representation learning will come from.

Things in the middle

  • The simplest thing to insert: a stack of linear functions (a circle with a plus is shorthand for one). k inputs, k could be 1,000, get compressed into, say, 3 numbers. Maybe 4 is right, maybe 10. How to choose comes later.
  • To learn smart representations, transform the inputs one or more times before doing the prediction. Flow the 3-dimensional vector through another function f(x):
The network, term by term (click a term, or let it cycle)
  • f(x) is called an activation function and it must be nonlinear, otherwise all the effort is a total waste of time. Take it on faith for now, the why comes in a few minutes.
  • Repeat as many times as you want, 100 if you like. Every transformation gives the network capacity to learn something interesting from the data. Capacity, not a guarantee.
DEFINITION · NEURAL NETWORK
A neural network is nothing more than repeatedly transformed inputs which are finally fed to a linear or logistic regression model. The input stays the same, the output stays the same, only the middle changes.
  • Explainability: for any input you know exactly how it flows through the network. What you cannot do is assign credit. The attributes get enmeshed in the middle, so no single input can be blamed for the outcome.
  • The number of layers and the functions inside them are design choices. The problem fixes the input and the output, we choose the middle.
  • Terminology: linear followed by nonlinear is a neuron (the brain link is loose and heavily argued, ignore it in practice). A vertical stack of neurons is a layer. The input layer is just the input, the output layer produces the output, everything between is a hidden layer.

Activation functions

  • An activation function receives a single number and outputs a single number. The linear function before it collapses 10 or 1,000 inputs into one scalar, and the activation transforms that scalar. That is all it is.
  • Sigmoid: 1 / (1 + e−a). Very negative inputs come out near 0, very large inputs come out near 1, and all the action happens in the middle range.
  • Linear activation: passes the number straight through. Barely deserves the name, listed for completeness.
  • ReLU (rectified linear unit), the hero of deep learning: max(x, 0). Positive numbers pass unchanged, negative numbers get squashed to 0. Many longtime practitioners believe ReLU is one of the key factors behind deep learning's success.
  • There is a menagerie of others (tanh, leaky ReLU, GELU, swish), but ReLU in the hidden layers gets practically anything done.
  • Rule of thumb: ReLU for hidden layers. The output layer is not a choice, the nature of the output dictates it. A single probability needs a sigmoid, 10 probabilities that must sum to 1 need a softmax.

Counting parameters

  • The first real network for the interview problem: 2 inputs (GPA, experience), one hidden layer of 3 ReLU neurons, a sigmoid output. Concept check from class: how many parameters does it have? Guesses were 12 and 9. The answer is 13, and the reason everyone says 12 is that they forget the biases.
  • The recipe. Weights: every arrow between consecutive layers is one weight, so multiply the layer sizes. Biases: every neuron that computes something has one, so count the neurons (the input layer computes nothing).
hidden: 2 inputs x 3 neurons = 6 weights + 3 biases = 9 output: 3 inputs x 1 neuron = 3 weights + 1 bias = 4 total 13
  • General rule for any layer: nin × nout weights plus nout biases. Sum over layers.
  • Habit to build: hand-calculate the parameter count the first two or three times you meet a complex network. Once you get it right a couple of times you never need to again, but it proves you understand what is connected to what.

The trained network is just a function

  • Say training (covered Wednesday) comes back with the best weights and biases it found. The network is ready for action. For any x1 and x2, each hidden neuron outputs its ReLU, and the output neuron combines them through the sigmoid.
  • The exact same network, written as math:
a1 = max(0, -0.3 + 0.5·x1 + 0.1·x2) a2 = max(0, 0.2 - 0.1·x1 + 0.3·x2) a3 = max(0, 0.5 + 0.2·x1 - 0.1·x2) y = σ(0.05 - 0.2·a1 - 0.3·a2 - 0.15·a3)
  • Written as one line it is a monster: y = 1 / (1 + e−(0.05 − 0.2·max(0, −0.3+0.5x1+0.1x2) − 0.3·max(0, 0.2−0.1x1+0.3x2) − 0.15·max(0, 0.5+0.2x1−0.1x2))). Super interpretable, right? The graphical layout and this function are equivalent, and the drawing is the one you can reason with.
  • Contrast with plain logistic regression: even this tiny network, one hidden layer of three neurons, is vastly more complicated as a function. The number of inputs has not changed, still two. From this complexity springs the ability to do magical things, provided you know how to train it. That is the secret sauce.

Wrap-up

  • Fully connected (dense) layer: every neuron's output is copied to every neuron in the next layer.
  • Logistic regression is a neural network with no hidden layers. Barely a neural network, the simplest one you can think of. Deep learning is just neural networks with lots and lots of layers.
  • A network where data flows strictly left to right is a feedforward network, in contrast to recurrent networks, which this class skips because transformers have proven more capable and become the norm.
  • The arrangement of layers, neurons, and activation functions is the architecture. Transformers and convolutional networks are just particular architectures.
  • The split to remember: inputs and outputs are given by the problem. Hidden layers, neurons per layer, and hidden activations are yours to choose. The output activation must match the output type.
  • Next lecture: how training actually finds the weights (loss functions, gradient descent), then ResNet gets fine-tuned in class, the first network to surpass human-level performance in image classification.

Q&A from the room

Why doesn't rules-based AI work?

Being time-intensive is not the real issue, computers keep getting faster. The killer is that hand-written rules do not generalize: there are an infinite number of new situations the rules never catered for.

How do you trust a model when the training labels themselves can be wrong?

Labels come from humans, e.g. radiologists marking mammograms, and that human judgment is the ground truth the model trains on. Labels will be wrong some small fraction of the time, so data needs to be complete, comprehensive, and correctly labeled. That said, neural networks still do a pretty good job even with some noise in the labels.

Will the class cover robotics and embodiment?

No, robots are embodied intelligence and there is no time for robotics, but much of what the class covers transfers.

Why write the model in graphical network form at all?

Partly usability when many functions flow through the network. The bigger point: the moment you draw it, you realize you could put lots of things in the middle instead of going straight from input to output.

Do we know which path an input took through the network? Who controls the number of layers?

For any input we know exactly how it flows through the network. The explainability problem is attribution: the attributes get enmeshed together, so we cannot easily give credit to any one of them. And the designer decides the number of layers and everything else in the middle.

Which functions have to be linear, and why?

The activations f(x) have to be nonlinear. A neuron is a linear function followed by a nonlinear activation.

How do you gauge which activation function suits your use case?

Hidden layers: use ReLU, it does an amazing job empirically. Output layer: you have no choice, the nature of the output dictates it. One probability means sigmoid; ten probabilities that must sum to 1 means softmax.

Can the network determine its own layers dynamically?

Not during training, the architecture stays fixed for optimization reasons. Searching over architectures is its own field, neural architecture search (NAS). The related trick the class will cover is dropout: randomly dropping nodes in a layer on each pass, an effective way to prevent overfitting.

Do we set the coefficients ourselves?

No. The whole name of the game is that training data plus a loss function plus an optimization algorithm let the network figure out its own weights so as to minimize prediction error.

What exactly is a node?

A linear function followed by a nonlinear activation. It receives a bunch of inputs, runs them through the linear function, passes the result through a ReLU or sigmoid, and out pops one number.

Design decisions first

  • Before designing a neural network you have to think through how many hidden layers you want, how many neurons in each layer, and what activation function to use. For the hidden layer activations there is nothing to decide: just go with ReLU.
  • Counting parameters: a layer of A units fully connected to a layer of B units costs A×B weights plus B biases. The heart disease network: 29×16 + 16 + 16×1 + 1 = 497.
  • Dense means fully connected: every unit in the layer connects to every unit in the neighboring layers.
  • The output layer activation is dictated by the output type. Binary classification needs a probability, so the output is one unit with a sigmoid.
inputs  = keras.Input(shape=(29,))
h       = keras.layers.Dense(16, activation="relu")(inputs)
outputs = keras.layers.Dense(1, activation="sigmoid")(h)
model   = keras.Model(inputs, outputs)

Training recap: lm and glm

Training linear and logistic regression
  • Training is finding values for the weights/coefficients so that the model's predictions come as close to the actual values as possible.
  • lm and glm use optimization algorithms under the hood to find these best values. You never had to see the optimization for regression. For neural networks we get to see how it is done.
  • Basically every trained model, even GPT, is the same thing. You have a skeleton of the model that lays out all the parameters, the weights and biases, and you have data. Then you use an optimization algorithm to minimize the loss, i.e. make the model's predictions as close to the actual values as possible.

Loss functions

  • The essence of training is to find the "best" values for the weights and biases, i.e. those that minimize a function that measures the discrepancy between the actual and predicted values. These functions are called loss functions in the DL world.
  • If the predictions are close to the actual values, the loss would be small. A perfect model would have a loss of zero.
  • In linear regression the error is quantified using sum of squared errors. So sum of squared errors is the loss function used in linear regression.
  • The loss function we choose must be matched well with the kind of output that comes out of the model.
